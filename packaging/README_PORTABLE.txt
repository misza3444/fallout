STREFA ZERO - Windows Portable (x64)

1. Rozpakuj CALY ZIP do folderu, w ktorym mozesz zapisywac pliki.
2. Uruchom STREFA_ZERO.exe. Nie uruchamiaj gry bezposrednio z ZIP-a.
3. STREFA_ZERO.pck musi pozostac obok pliku EXE.

Bez instalatora. Nie wymaga Godota ani przegladarki.
Docelowo: Windows 10/11 x64, sterownik graficzny z OpenGL 3.3.

Zapisy i ustawienia: folder userdata obok EXE.
Przenos caly folder gry razem z userdata, aby zachowac postep.
Przy aktualizacji zachowaj dotychczasowy folder userdata.
Zapis z przegladarki nie przenosi sie automatycznie do wersji Windows.

WASD/strzalki - ruch; mysz - rozgladanie; Shift - bieg;
Ctrl - obnizenie kamery; Spacja - skok; E - skan; Esc - pauza.
Menu > Wyjscie > Zapisz pozycje gracza zapisuje wyprawe.
Przycisk Zamknij gre konczy dzialanie aplikacji.

Pre-alpha: nie ma jeszcze pelnej walki, NPC, ekwipunku ani zadan.
Build deweloperski; informacje o kompilacji w BUILD_INFO.txt.
